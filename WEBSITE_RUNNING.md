## 🚀 Keep It Running

To keep the website running:
1. **Keep the Command Prompt window open** (don't close it)
2. The server stays active as long as the window is open
3. To stop: Close the Command Prompt window

## 🔄 Restart If Needed

If you close the window and want to run again:
1. Double-click the file: `run-dev.bat` in your project folder
2. Then open `http://localhost:3000` in browser

## 📝 Quick Commands Reference

**From Command Prompt in your project folder:**

```bash
# Run the website (uses run-dev.bat automatically)
run-dev.bat

# Or manually via full path npm:
"C:\Program Files\nodejs\npm.cmd" run dev
```
