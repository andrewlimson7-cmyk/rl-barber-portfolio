## ❓ Quick Help

**Images not showing?**
- Verify `public/images/` has all files
- Check file names (1.jpg, 2.jpg, etc.)

**Styles not working?**
```bash
rm -rf .next
npm run dev
```

**Port in use?**
```bash
npm run dev -- -p 3001
```

**Need to reinstall?**
```bash
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```
