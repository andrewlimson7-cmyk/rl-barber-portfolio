# RL Barber - Premium Portfolio Website

A luxury, award-winning portfolio website for a professional barber named RL Barber. Built with Next.js, React, Tailwind CSS, Framer Motion, and GSAP.

## 🎨 Features

- **Premium Design**: Luxury aesthetic with gold accents and glassmorphism
- **Animated Preloader**: Custom barber pole loading animation
- **Custom Cursor**: Luxury gold cursor with glow effects
- **Smooth Animations**: GSAP and Framer Motion powered animations
- **Responsive**: Perfect on desktop, tablet, and mobile
- **Portfolio Gallery**: Masonry layout with image filtering and lightbox
- **Booking System**: Appointment booking form
- **Testimonials**: Client reviews with carousel
- **Services**: Pricing and service showcase
- **FAQ**: Accordion with common questions
- **Contact**: Multiple contact methods

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ installed
- npm or yarn package manager

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open browser
# Visit http://localhost:3000
```

### Build for Production

```bash
npm run build
npm start
```
